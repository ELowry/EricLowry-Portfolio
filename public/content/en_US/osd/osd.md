# Open Source Development

Like I suspect is the case for many developers, most of my open-source work resulted from questions like _"Why isn't this easier?"_, or _"Can I automate this?"_.

All these projects began as personal projects, tools, or simple scripts meant for my own use, usually to remove friction from my workflows, or because I was frustrated by the lack of existing solutions to a problem.

I fully believe that a good solution to a problem is meant to be shared; so when I have had time, or have been particularly motivated, I took the time to polish their user experience, write documentation, and make them available.

Over the years, I've written dozens of similar tools (most of which are proprietary), but this selection of open source and source-available projects should serve as a good window into my work as a developer.

You can explore more of my work on [my GitHub page](https://github.com/ELowry).

## Projects

**[InputLayers](gaming/InputLayers)**:  
Custom layer-based filtered input management built on top of Unity's Input System to easily manage input exclusivity for complex UIs and game states.

**[WinGet Updater](osd/winget-updater)**:  
A lightweight, portable PowerShell tool designed to silently automate Windows application updates in the background using WinGet.

**[Marked Responsive Images](osd/marked-responsive-images)**:  
A Marked.js extension that parses standard Markdown image filenames to automatically generate responsive HTML `<picture>` elements.

**[Obsidian Replace Commands](osd/obsidian-replace-commands)**:  
An Obsidian plugin that allows users to build, preview, and execute sequential chains of regex search-and-replace queries as single-click actions.

**[DNS Toggle](osd/dns-toggle)**:  
A tiny Android Quick Settings tile to quickly toggle their device's Private DNS setting.

**[StadiaIcons](osd/StadiaIcons)**:  
A Progressive Web App and icon library built to create seamless native desktop shortcuts for the now-defunct Stadia cloud gameing service.
